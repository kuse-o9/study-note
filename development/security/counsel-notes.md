# 非公開の恋愛相談（人による回答）

利用者は `counsel.html`、管理者・オーナーは管理者ページの「恋愛相談への回答」から `admin-counsel.html` へ進む。利用者には人が回答すること、遅れる場合、守秘、返信のためのサーバー保存を説明する。AI送信・有料サービス・端末への自動下書き保存はない。家族連携で相談の閲覧権限を追加しない。

新規の非公開テーブル3個はRLS有効、anon/authenticated/service_roleから直接アクセス不可。単一RPCはメール確認済みの有効セッション・メンテナンス判定を維持。本人以外の利用者は一覧・本文・返信・終了を拒否。対応者は管理者専用パスワード確認済みの現役管理者で、8時間以内のセッション単位の守秘確認が必要。返信時にも必ずチェックを要求する。相談者のメール・アカウントIDを返信APIの応答に含めない。管理者一覧では件名・本文も出さず、開いた相談だけ取得する。本文はtextContentで表示。1相談60通、対応中3件・30日10件、8000文字、連続送信15秒、ページ20件、総DB容量400MiBの安全弁。再送IDによる重複防止・revision競合検出あり。

検査：PGlite25項目、本番の実RLS/権限で本人送信→他人拒否→専用パスワードなし拒否→守秘未確認拒否→返信チェックなし拒否→確認済み返信→本人閲覧をROLLBACK検査。検査用アカウント・相談は0件に戻ったことも確認。画面は非公開の模擬データでチェック未選択拒否、回答、HTML文字列の無害表示を確認。

守秘の注意書きは運用規則であり、スクリーンショットや人の口外を自動防止できる保証ではない。違反は最高オーナーが確認する。最高オーナー限定の権限解除RPCと画面追加はローカル10項目検査済み。Supabase確認が2回期限切れの後、3回目で反映成功。実行時に対象者の管理者・オーナー役割と本人確認・守秘確認を解除し、保護された操作履歴を残す。最高オーナー自身、他のオーナーによる操作、本人確認なし、対象確認なしは拒否する。実際の利用者の役割は変更していない。
