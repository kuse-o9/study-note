# アプリマーケット・家族連携・集中モード

入口：上部「アプリ・設定」→「アプリマーケット」「集中モード」「家族の設定」。

9種類：動画編集、ゲーム、学習タイマー、勉強の掲示板、勉強チャット、協力ミッション、お知らせ、管理者のつぶやき、学習用BGM。すべて既存機能の無料の追加・取り外し。取り外しても作品や運転記録・学習データを消さない。移行時の既存4アカウントは9種類を登録済みとし、その後の新規アカウントは空で始める。

家族設定で保護者／子供を選択。保護者が24時間有効・一度限りの招待コードを作り、子供が相手の名前と影響を確認して承認する。保護者は連携した子供の9機能の利用制限と集中時間を設定できる。個人デッキ・ノート・チャット本文の閲覧権限は与えない。他人の家族の設定は拒否する。連携中の子供による区分変更・制限解除を拒否。保護者1人につき子供10人の連携、未使用招待3件、集中時間最大240分。設定は原則15秒以内に再確認する。

集中モードは選んだ拡張機能を一時停止する。通常のデッキ・暗記ノート・アカウントと家族設定は利用可能。自分の集中モードを終了しても保護者の制限は解除できない。該当ページの背景操作を inert とキーイベント制御で止める。動画再生／書き出し、BGM、タイマー、ゲームは制限更新で停止。3Dの起動は許可確認後に行う。

サーバー：Supabaseの非公開スキーマに設定を保存し、テーブルはRLS有効・ブラウザーから直接読み書き不可。認証済み・メール確認済み・有効セッションと既存メンテナンス判定を維持する。公開RPCは本人または承認済み連携先だけを扱い、revisionで競合を検出。掲示板・チャット等のRPC、運転記録と共有音楽・写真のRLSにも機能制限を適用。個人用の設定に管理者権限を流用しない。

検証：PGlite17項目、クライアントの未追加／ゲスト／直接URL／外部リンク／認証切替／背景操作復元の検査、34画面のナビゲーション検査、島のESM構文確認。本番では新規の一時アカウントとセッションで招待承認・再使用拒否・他人の家族操作拒否・子供の制限解除拒否を検査し、全書き込みをROLLBACK。公開マーケットをブラウザーで確認。家族フォームのブラウザー表示・保存操作は非公開のローカル模擬データで確認。実アカウントのブラウザーからの家族登録は未実施。

制約：GitHub Pagesの静的ファイルそのものを端末全体で遮断するものではない。コピーした公開コードや別のアカウントまで制御する保証はしない。snote.github.io は GitHub の snote アカウント／組織とそのユーザーサイトの管理権限が必要で、接続済み権限では確認できないためURLは未変更。現在の正規URLを維持する。

有料サービス・外部AI呼び出し・追加の有料ホスティングは使用していない。
