# カメラ切り替え・一括書き出し

素材を追加トラックに同時刻で並べ、クリップの編集ツールに同じカメラグループと別のカメラ名を設定する。再生位置を合わせて「再生位置からこのカメラに切り替える」を押す。切り替え点は元のクリップを壊さず保存し、プレビュー・通常出力・コマ単位出力の映像と音声に適用。音声は速度カーブの積分と切り出し区間を共有する。自動同期・複数モニター・ネストは未対応。切り替え点で選んだ素材の存在しない時刻は表示がないので、素材の長さを確認する。

「編集ツール・自動保存」→「一括書き出し」から横1080p・縦1080p・正方形を選ぶ。現在の形式で逐次エンコードしてZIPにまとめる。最大3本、各120秒、合計256MiB。ZIPは非圧縮STORE/UTF-8/CRC32、元映像の再圧縮は動画エンコーダーだけ。外部アップロード・有料APIなし。対応できないサイズ/形式を勝手に下げない。中止・失敗・成功時に元の解像度・再生位置と操作可能状態を戻す。家族・集中モードによる利用制限で中止する。録音と出力の同時開始は拒否する。

検査：純粋関数18項目、Python標準zipfileでCRC/UTF8/パス安全性、ブラウザーで保存済みプロジェクト→2素材再接続→2サイズ出力→ZIP展開→ffprobeサイズ/映像音声確認、ffmpegで切り替え後の色と440Hz→880Hzの音声を確認。従来の切り取り・LUT・字幕・プロジェクト入力・MediaRecorderエラー時の解放検査も合格。検査素材・模擬認証は公開しない。
