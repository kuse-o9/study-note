# 軽量プレビュー素材（無料・端末内処理）

動画クリップを選択→編集ツール・自動保存→軽量プレビュー素材。120秒までの元動画から最大1280×720・30fpsのWebMを端末内で作成できる。画面のボタンを押したときだけ生成し、有料APIや外部アップロードはない。別途作った軽量動画の接続にも対応。長さは0.15秒以内、縦横比は2%以内で検査し、内容そのものが同じかは利用者が確認する。素材名だけをプロジェクト/自動保存に記録し、再読込では元動画・軽量動画を選び直す。メディアのバイト列は自動保存しない。

プレビューの低解像度化は利用者の選択時だけ。書き出しはMediaRecorder・コマ単位・一括とも元動画。色ノード/LUTが有効なクリップは編集中も元動画を使い、軽量画像が出力に混入するのを防ぐ。位置・クロップ・マスクは正規化座標を維持する。解除・アカウント切替・離脱で軽量URLと再生インスタンスを破棄し、WebAudioの各ノードも切断する。家族/集中モードの利用制限と中止ボタンに従う。

検査：12項目のサイズ/長さ/縦横比、実際のinstance関数で書き出し時・色処理時の元動画選択、従来のプロジェクト検査15項目、カメラ/ZIP検査18項目、失敗時解放4項目などが合格。ブラウザーで生成・接続・保存を確認。あえて内容の異なる緑色動画をプレビューとして接続し、出力は元動画（1920×1080、元のカメラ映像）であることをffmpeg/ffprobeで確認した。対応端末や素材による速度差があり、常に軽くなる保証はしない。HDR、専門形式、手ぶれ補正、追跡、共同編集等の未完了項目を完了扱いにしない。
